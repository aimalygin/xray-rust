# Diagnostic control sources

These are the actual Go control sources, formatted with `gofmt` after collection; original source digests are in `../private-input-digests.json`. They are diagnostic probes, not production components or performance benchmarks. The Python server below has portable command-line startup in place of the original private path/configuration lookup; its request/response behavior is unchanged.

- `fixture.py`: imports the repository's Android fixture and logs UDP backend receive addresses and nonce hashes. `ISSUE56_UNFIXED=1` removes the source binding for a baseline; `ISSUE56_DECOYS=64` adds the owned IPv4 competing listeners used in the controlled challenge. Command-line arguments are those of `scripts/run-v07-apple-protocol-fixture.py` (`--protocol v08`); retain the generated private files outside this report. This is the original diagnostic source with formatting and portable repository lookup only. Stop it after the bounded device series; no competing sockets persist beyond its process.
- `android-socks/main.go`: exactly four rounds of 240 HTTP and 480 UDP requests through a local SOCKS listener, 32 workers, 5-second deadlines and 20-second recovery. Arguments: `socksPort tcpBackendPort udpBackendPort`. UDP logs include nonce hash, client port, relay port and start/finish time from the same Android clock. Requests target the fixture's synthetic `198.51.100.1` destination.
- `android-reuseport/main.go`: hold 32 IPv4 loopback listeners, allocate 10,000 further listeners, count overlaps, then repeat without reuse. Socket option 15 is Linux/Android `SO_REUSEPORT`; this probe is for Android, not macOS. All sockets close before exit. A zero-collision run does not disprove a probabilistic collision.
- `direct-tcp/main.go`: plain TCP HTTP control, arguments `host:port requestCount` (4,096 in this report); 32 workers and separate 5-second connect/response deadlines. Each failure records its stage. `direct-tcp/server.py` logs received nonces and returns HTTP 204. Run the same probe once against an owned `adb reverse` port and once against the server's LAN address, with VPN stopped; remove only that test forwarding rule afterward. No proxy participates.
- `reference-observer/main.go`: macOS socket read/write wrapper using the pinned Xray source's `UseAlternativeSystemDialer` hook. Argument: path to a generated fixture `server.json`. Build in a separate Go module with a `replace github.com/xtls/xray-core => /path/to/pinned/reference` directive; the reference checkout remains unmodified. This wrapper preserves the default dialer and adds logging, so it must not be used as a canonical throughput sample.

The three standalone Android Go probes use only the standard library. Build each source with Go 1.26.5, `GO111MODULE=off GOOS=android GOARCH=arm64 CGO_ENABLED=1` and the NDK compiler specified in the parent report. Use a separate temporary device directory and remove only the owned probe files after execution. Creating a new run requires a reachable, privately generated fixture; this report deliberately does not publish server credentials or phone identifiers. Retain all failures and non-reproductions rather than repeating until a pass.
