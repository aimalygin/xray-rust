# 0.10.1 candidate measurements — 2026-11-17

**Publication authorized with explicit 0.10.1 limitations; distribution gates pending.**
This report holds the device and performance evidence of the 0.10.1 candidate.
- Asked on 2026-11-18 «Выпускать 0.10.1 с этими ограничениями и публиковать свидетельства?»,
  the owner answered «Да, публикуй».
- The [0.10.1 decision record](../../releases/v0.10.1-owner-decisions.json) lists the owner's
  decisions and the accepted known limitations.
- The owner chose to repeat only what this release touches («Только затронутое»). Three runs
  that it does not touch are carried over from the 0.10.0 release's build. Every table below
  names the build behind each result.
- Every failed attempt of a counted run is kept under [failed/](failed/) with its cause.
