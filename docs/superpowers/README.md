# Historical design notes

The `plans/` and `specs/` files in this directory are implementation records
from earlier development work. They are retained for design context, but they
are not the supported user documentation and may describe intermediate APIs,
commands, or behavior.

Use the curated documents linked from the repository
[README](../../README.md) for the current status, configuration surface,
integration contract, and verification commands. When a historical note
conflicts with current code or those documents, the current code and curated
documentation take precedence.
